## v1.17.1 · 2026-10-29

**一句话**：家长面板里，六个年级的「定理与定律」现在都标了课本位置。

**你会看到**

- 人物 → 家长 → 知识点掌握，每个知识点下面那行小字写着「在课本哪一册哪一单元」。说法题那六条以前是空的，现在补上了。
- 说法题本来就不是某一单元的题——它把整册的定义、公式、换算拿出来问，所以位置写成「**每册主要几单元 等**」，不是精确到某一页。
- 这一版补的是**人教**课本的位置。用北师、苏教、冀教的话，这一栏仍会显示人教的说法；但「几年级出这道题」是按你那版单独核过的，不影响会不会抽到没学过的东西。

## v1.17.0 · 2026-10-29

**一句话**：「定理与定律」六个年级全都有了，每级 12 道。

**你会看到**

- 二到六年级也补满了。一年级那批是试点，现在**六个年级一共 72 道**——不管你在哪个年级的数域里，都会遇到。
- 每级都是 **8 道挑符号、4 道从四句里挑对的那句**。挑符号的一眼能答，用来稳概念；四句的那类才考真本事。
- 错的那三句不是随便编的：一句错在**方向反了**、一句错在**把两个概念互换**、一句错在**方法**。你选哪个，就知道哪一处没记牢。
- 每道题都只考该年级课本上写过的东西。教材位置还没核完，等核完再补一句「在哪一册」。

## v1.16.0 · 2026-10-29

**一句话**：多了一种题型——「定理与定律」：考的不是算得快，是课本上那句话怎么说的。

**你会看到**

- 每个年级的数域里多了一个知识点「**定理与定律**」。题长得跟以前不一样：不给你数算，而是问「**下面哪一句是对的**」，四个选项都是这个年级学过的说法，只有一句没错。
- 还有一类是**挖掉一个成分**：`长方形的面积 = 长 □ 宽`，让你挑那个符号。这类一眼能答，用来先把概念稳住。
- 选项里的错句不是随便编的，各自对应一种典型混淆：**把周长写成面积、把单位换算写成 10 倍、把正方形当成长方形**。你选哪个，就露了哪一处没记牢。
- 这一版每个年级先放 **2 道**，把题型和排版跑通；后面补齐到每级 12 道。

## v1.15.2 · 2026-10-29

**一句话**：练习阁里多了「听过的讲解」——讲过的那些，随时能再听一遍。

**你会看到**

- 练习阁底下多了一行「**听过的讲解**」，后面跟着数字，那是你已经听过几条。点开按年级翻，挑一条重听。

- 听完直接回练习阁，不用折回地图。

## v1.15.1 · 2026-10-29

**一句话**：讲解换了位更像先生的人来讲；同一个知识点讲过就不再絮叨，还能一键跳过。

**你会看到**

- 讲知识点的那位「引路人」换了样子：**束发、长袍垂地、留着短须**，个子也高了些。原来他看着像个大孩子，开口却是长辈的语气，人对不上。
- 同一个知识点**第一次讲四句，之后再错到它只讲两句**——先用一句说清是什么，不再把同一段当噪音放第三遍。
- 讲解的演出右下角多了一个「**跳过 ▸**」。序章、结局、守律者的台词没有这个键，那些还是得听。

## v1.15.0 · 2026-10-29

**一句话**：旧影的讲解，现在从一年级到六年级 74 个知识点全都讲得出来。

**你会看到**

- 上一版只有三年级 10 个知识点有讲解，其余遇到错题只挡一下、不开口。现在 **74 个全都补齐**——不管你在哪个年级的域里错了题，回图前都有一段。
- 每一段都是四句：一句开头 + 三句正题。不讲你错的那一道，只讲那道题背后的那个知识点。
- 难度题（找规律、找次品、鸽巢、优化问题这类）讲的是「怎么入手」，不是「公式是什么」——这类题本来就没有一个公式能概括。
- 还是那句话：**有没有旧影都听得到**。没有的话，由书院的引路人讲同一段。

## v1.14.0 · 2026-10-29

**一句话**：答错时旧影替你挡一下；打完它把这题背后的道理讲一遍。

**你会看到**

- 现在你手上有旧影了。战斗中**第一次**答错，它会替你挡掉那一下 —— 每场只挡一次，挡完那句写得很直：「下次自己来。」
- 打完点「回到地图」，它会讲一段：**只讲这道题背后的那个知识点**，四句话，不针对你错的那一道。讲透一个，比连讲五个有用。
- 一场只讲一个。要是这局错了三个知识点，它挑**错得最多**的那个讲。
- 结算页会先出现一行小字告诉你：谁要讲、讲哪个 —— 不至于点了按钮突然冒出一段戏。
- **这一段不是奖励。**「听讲解」这件事跟有没有旧影无关：没有旧影的孩子，同样的讲解由书院的**引路人**讲。
- 这一版先做**三年级 10 个知识点**（两位数乘一位数、两位数除以一位数、长方形周长、长方形面积、单位换算、时分秒换算、两位数乘两位数、年月日、位置与方向、复式统计表）。其余年级陆续补。

## v1.13.0 · 2026-10-29

**一句话**：大地图多了一格「旧影台」——一场打不完的仗，撑到倒下时有人接手。

**你会看到**

- 通关任意一个数域之后，世界图上多出一格「旧影台」。
- 进去那只影子**怎么也打不完**：血条厚得不讲道理。你先答对八道，它就在旁边看着。
- 等你真的撑不住、**血被打空的那一刻**，它现身，讲完自己为什么留在这里，然后替你收场，留下一缕给你。
- **一路答对也不用担心**：答到十二道，它会说「这一程你没让我出手」，照样把灯留下。两种走法都拿得到 —— 不用为了看它而故意答错。
- 拿到的那一位会记在旧影台里。**这一版它还不进裂隙**，那一步放在下一批。

## v1.12.0 · 2026-10-29

**一句话**：裂隙里快撑不住的时候，会有「先来过这里的人」替你削一刀。

**你会看到**

- 打数境裂隙时，血掉到三成以下，隙缝里会探出一道影子——那是以前打过这里的同龄孩子留下的。它替你削掉敌人一刀（约 6% 血），并替你挡掉下一次伤害的一半。
- 一位前辈每场只出现一次。而且它**不抢你的最后一击**：哪怕那一刀够把怪打死，也会给怪留一口气，收尾永远留给你。
- 它说的话都很短，比如「这道我卡过三回，第四回就通了」「慢一点，没人催你」——你只会遇到**同年级**的人。
- 只在裂隙生效。主线和野图没有——那里还没有「别人来过」的痕迹。

# 附录一 · 还没有版本号的那些天（10-09 ~ 10-16）

> 这 6 天没有版本号（四位差制 10-19 才建立），但游戏真正的骨架全在这里。下面按「做成了什么」写，不按批次。

## 一 · 起点：本来只想做一张口算卷（10-09 上午）

**一句话**：先做了 14 分钟的小程序口算卷，然后推翻，改成「双击就能玩」的单文件网页游戏。

- **10-09 上午 10:00**，第一版是微信小程序形态的「五年级小数运算题库」：10 道口算、6 道简算和竖式、2 道应用题。
- **10:20 换方向**：不装、不联网、不注册，一个 HTML 文件双击就开。这个决定一直用到现在。
- 当天下午的版本只有一件事：「出一道题 → 你答 → 下一题」。

## 二 · 六个数域，一个年级一域

**一句话**：把「做题」装进一张能走的地图——六个数域走完，正好是小学六年。

| 数域       | 年级  | 这一域在教什么               |
| -------- | --- | --------------------- |
| **萌芽原野** | 一年级 | 20 / 100 以内加减、比大小、找规律 |
| **风车水乡** | 二年级 | 乘法口诀、表内除法、认识时间、钱币     |
| **齿轮山谷** | 三年级 | 多位数乘除、周长与面积、单位换算      |
| **云顶书院** | 四年级 | 四则混合、运算定律、小数加减、角      |
| **星轨天穹** | 五年级 | 小数乘除、分数加减、方程、体积       |
| **苍穹雪原** | 六年级 | 分数乘除、比与比例、圆、百分数       |

**你会看到**

- 每个数域是一张能走的地图：草丛里有怪、有宝箱，还有迷雾——不走过去看不见。
- 走到底会遇到这一域的**守律者**，打服他，这一域就算「定」了。

## 三 · 答题就是打架

**一句话**：答对，你的角色出手；答错，站着挨一下。

- 血量归零就力竭，回地图重来，掉的东西不丢。
- 战斗里能用药、能用符、能放技能，攒的算珠和装备在这里起作用。
- **守律者会掉他身上的装备**，装备有品级、有词条（加攻、加血、加算珠），可以反复刷更好的。

## 四 · 从几年级开始，不用从头刷

**一句话**：开局先考一次，按成绩定起点；打一域升一格。

- **入学考**：开局考一次，定你从几年级开始。
- **升学通路**：地图上每一域会标「主战场 / 试炼 / 游历 / 旧地重游」——告诉你这一域是新课、复习、还是超前。
- **通关顺延**：打完一域，就读年级自动往上抬一格，下一域变成你的主场。
- 头像旁边一直挂着你现在的年级，看得见自己长到哪了。

## 五 · 书院：算珠有地方花了

**一句话**：四个摊位 + 一个裂隙专属的「隙市」。

- **百草摊**（药）/ **器物摊**（装备）/ **玄机阁**（贵、限量、长本事的）/ **风物铺**（风味与收集）。
- **隙市**：只收裂隙里挣的「隙尘」，卖门票、洗点、重开与限量好物。
- 后来还加了「先冻住对手」的**冰封丹**：冻到下一次作答为止，一场只能用一次，在守律者面前冻不住。

## 六 · 图鉴、成就、家长页

**一句话**：玩过的东西有地方看，学得怎么样有地方查。

- **图鉴**：怪物、装备、技能、数章四类；没收到的显示剪影和「?」，收满给奖励。
- **成就**：战斗、学业、收集三类，做到了就亮。
- **家长页**：按知识点列出「哪些还没打牢」，能复制周报、导出图片，直接发给老师。

## 七 · 竖式能填了，守律者还会追问

**一句话**：竖式从「看」变成「写」，打完还要说清「你是怎么想的」。

- **竖式演算板**：答案位、进位位、退位位都要自己填；错了会告诉你「是进位错了」还是「答案错了」，并给出逐位解释。
- **守律者的追问**：通关后他会问你一句思路题，答对才授这一域的专属称号。
- **称号能戴**：名字旁边会显示你选的称号。

## 八 · 数境裂隙（10-16）

**一句话**：六域各有一道裂缝，进去是三层地窟——怪更硬、题更难，挣的是外面没有的东西。

- 三层地窟，有迷雾、有宝箱、有下行梯；第三层守着「隙影」。
- **裂隙里只出难题**：普通题一道都不进，进去就是硬仗。
- 里面挣「隙尘」，难度越高掉越多；隙市里用隙尘换限量货（属性珠、精锻装备匣、补给）。
- 裂隙里没有倒计时——**隙中无时**，可以慢慢想。

## 九 · 八十多条拔高题，铺满六域（10-16）

**一句话**：不是把数字改大，而是真的换了一种题。

- 凑整、配对求和、基准数、分配律正反用、黄金搭档（25×4 / 125×8）。
- 盈亏、鸡兔同笼、得失分、三阶幻方、数阵、周期、真假话、顺序推理。
- 六域每个知识点都有，总共八十多条，全部「一题三档」——简单、中等、困难都出得成题。

## 十 · 书院扩容（10-16）

**一句话**：货架从「没几样可买」变成有得挑。

- 新增 17 件商品，四个摊位各有性格；加了限购与收藏称号。
- 商店入口统一进裂隙、探索和大地图，不用再绕。

# 附录三 · 这份文档怎么用

| 场景                                    | 用哪份                                   |
| ------------------------------------- | ------------------------------------- |
| GitHub Release / itch.io 更新说明（只写最近一版） | `docs/02-更新公告/更新公告.md` 最新那一段                  |
| 发布页「全部更新」/ 仓库 CHANGELOG / B站专栏末尾       | **这一份**（从头贴到尾，最新在最上面）                  |
| 微信群一句话                                | 各版本下面的「一句话」，或顶部的「版本速查」表                  |
| 游戏内「本次更新」小卡                           | 只取最新版本的前 3 条（写在 `UPDATE_NOTE` 里）      |
| 想知道某一版为什么这么改                          | 开发环境里的逐版「更新内容说明」（工作汇报，不随仓库发布，也不给玩家看） |
| 想知道改了什么代码、动了哪个字段                      | 开发环境里的版本变更日志（**不要贴到发布页**） |

**写新版本时，改三处**（**最新放在最上面**）：

1. **版本速查表**第一行上面插一行；
2. **正文**在 `## vX.X.X` 那一堆的最上面（紧跟「版本速查」下面那条横线）插一整段；
3. 如果动了题库（加知识点 / 改变式），**附录二**编辑器表最上面也插一行「跟随 vX.X.X：左栏 N 个知识点 / M 个变式」。

格式照短版 `docs/02-更新公告/更新公告.md` 末尾的模板：`## vX.X.X · 日期` → **一句话** → **你会看到**（玩家能具体看到/做到的一条一句）。

**别忘的**：短版只留最近几版，这份是全历史 —— **两份一起改，别只更一份**。
